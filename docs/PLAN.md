# Lakers rebuild status

The [Lakers proposal](LAKERS_PROPOSAL.md) was approved. The broader NBA product has been replaced with a personal Lakers statistical workspace.

- Real data: 82 regular-season games from 2025-26 and three completed 2026-27 preseason games imported from ESPN. Coverage and failed checks remain visible.
- Game investigation: linked period/time selection, score margin, shooting, rotations, player totals, possession units, and event search.
- Cross-game research: common filters, player logs and shooting, lineup/on-off samples, comparison pinning, immutable saved results, and CSV exports.
- Operations: cached source revisions, repeat-safe imports, optional hourly refresh, offline access to imported games, local launch script, Docker configuration, and regression tests.

Read DATA_VALIDATION.md for the checked dataset, calculations, and remaining limits. Richer tracking/play-type data, league benchmarks, multi-season studies, uncertainty modeling, and a natural-language interface remain optional later work.
