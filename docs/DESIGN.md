# CourtVision workspace

The visual reference is a Lakers scorebook: a compact purple navigation rail, a prominent game score, and a white analysis surface. Statistical comparisons carry the page. Color identifies the Lakers, their opponent, or a selected sample.

| Token | Value | Purpose |
| --- | --- | --- |
| Court purple | #552583 | Lakers identity and selected states |
| Gold | #FDB927 | Opponent series and selected timeline stretch |
| Ink | #252332 | Text and chart labels |
| Paper | #FCFCFF | Main surface |
| Lavender | #EEE9F5 | Quiet grouping and selection backgrounds |
| Teal | #176B58 | Positive differentials |

Use Avenir Next with Segoe UI and sans-serif fallbacks for controls, prose, and tables. Condensed Impact/Arial Narrow display type gives the score its basketball character. Tabular numerals align comparisons. Keep content left aligned, except numeric columns and the scoreboard.

```text
Navigation | Season / sample controls              Saved research
           | Matchup                     Lakers score / opponent
           | Period and time selection
           | Key rates and sample size
           | Score margin timeline    | Shooting map and zones
           | Rotation timeline        | Player totals
           | Underlying possessions and source checks
```

Review against the brief: the prominent score belongs specifically to game analysis; a decorative marketing hero would displace useful information. Purple is restricted to navigation and selection so dense numbers remain readable. Use table rules for comparisons and rounded boundaries for interactive panels, rather than repeating identical cards. Provide keyboard equivalents for chart filtering, accessible contrast, narrow-screen stacking, and no decorative motion.
